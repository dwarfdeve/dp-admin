# Dwarf Plug Shipping & Order Tracker

**Internal Order Management & Customer Tracking System**

This is the backend admin tool for **Dwarf Plug**—a premium cannabis logistics and delivery service. It manages order tracking, payment confirmation, shipping status updates, and customer notifications.

## Features

- **Order Parsing**: Paste orders from Telegram and automatically extract customer info, items, and shipping details
- **Status Management**: Track orders through 5 stages: Received → Confirmed → Packed → In Transit → Delivered
- **Payment Tracking**: Record payment method and confirmation timestamps
- **QR Code Generation**: Generate scannable tracking links for customers
- **Professional Receipts**: Print-ready order receipts with branding
- **Customer Sharing**: Generate shareable tracking links for customers to monitor their orders
- **Internal Notes**: Add private notes for team coordination
- **PDF Export**: Export orders as PDF for records

## Workflow

1. **Receive Order**: Customer places order on the shop (dwarfplug.com)
2. **Parse Order**: Admin pastes order details into the tracker
3. **Confirm Payment**: Mark payment as received with timestamp
4. **Update Status**: Progress order through shipping stages
5. **Share Tracking**: Generate QR code and share link with customer
6. **Archive**: Export as PDF for records

## Integration

- **Shop**: Orders collected from [Dwarf Plug Shop](https://github.com/dwarfdeve/Dwarf-plug)
- **Telegram**: Share tracking links and status updates via Telegram
- **Customers**: Track their orders via shareable links with QR codes
